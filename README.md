# NIST SP 800-53 Security Control Mapping

## Project Overview
This project demonstrates the application of NIST SP 800-53 Revision 5 security controls to identified cybersecurity risks within a simulated higher education environment.

The assessment was conducted as part of graduate-level Cybersecurity Risk Management coursework at Old Dominion University.

## Organizational Scenario
Premier University is a fictional institution serving approximately 15,000 students and 2,000 faculty and staff. The university maintains sensitive student records, financial systems, learning management systems, and administrative networks.

A simulated cybersecurity assessment identified four security risks requiring appropriate security control recommendations.

## Assessment Objectives
- Identify organizational cybersecurity risks and security requirements.
- Map identified risks to appropriate NIST SP 800-53 Rev. 5 controls.
- Explain how selected controls mitigate security risks.
- Recommend practical security control implementation measures.
- Identify potential audit evidence to support control verification.

## Risk and Security Control Mapping

| Identified Risk | NIST Control | Control Title |
|---|---|---|
| Unauthorized Access | AC-6 | Least Privilege |
| Missing Security Updates | SI-2 | Flaw Remediation |
| Inadequate Audit Logging | AU-6 | Audit Record Review, Analysis, and Reporting |
| Weak Backup Procedures | CP-4 | Contingency Plan Testing |

## Assessment Methodology
1. Reviewed the simulated university cybersecurity scenario.
2. Identified security requirements associated with each risk.
3. Referenced NIST SP 800-53 Revision 5 to select appropriate security controls.
4. Evaluated how each selected control addresses the identified risk.
5. Developed practical implementation recommendations.
6. Identified potential audit evidence for future control verification.

## Key Recommendations
- Implement role-based access control and periodic user access reviews.
- Establish automated patch management and vulnerability remediation procedures.
- Centralize security logs using a Security Information and Event Management (SIEM) solution.
- Conduct periodic backup restoration and contingency recovery exercises.
